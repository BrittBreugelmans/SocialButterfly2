# Contract: Language (i18n)

How every feature shows text in Dutch and English (FR-015, FR-016).

## Rules

- All user-facing text comes from the dictionaries. No hard-coded strings in components.
- `nl` is the source dictionary. `en` MUST have exactly the same keys; a missing key is a
  build (type) error.
- Keys are grouped per feature: `app.*`, `storage.*`, `install.*`, `offline.*`, later `event.*`,
  `guest.*`, …
- Fixed texts from `wiki/merk-en-stijl.md` are used word for word.

## Interface

```ts
type Language = 'nl' | 'en'

useLanguage(): {
  language: Language
  setLanguage(language: Language): Promise<void>   // updates screen at once and Settings.language
  t(key: TextKey, params?: Record<string, string | number>): string
}
```

- `setLanguage` changes all visible text without reload (US3, scenario 1) and stores the choice
  (US3, scenario 2).
- Before Settings are loaded, the default `nl` is used.
- Guest mode (F3) can switch the display language for the guest on the same interface.

## F0 keys (minimum)

| Key | Purpose |
|---|---|
| `app.title` | App name: NL "De Sociale Vlinder", EN "The Social Butterfly" (FR-003) |
| `app.languageSwitch` | Label of the NL/EN switch |
| `offline.message` | Full-screen friendly "needs internet" message when the app starts offline (FR-005) |
| `offline.banner` | Non-blocking banner when the connection drops while the app is open (FR-005) |
| `storage.notPersisted` | Warning when iOS does not keep data permanently (FR-007) |
| `storage.full` | Message when saving fails because the device is full |
| `install.hint` | "Add to Home Screen" guide in a Safari tab (research R3) |
